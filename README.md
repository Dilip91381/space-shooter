# 🚀 Space Shooter Game

## 📌 About the Project
Space Shooter is a simple browser-based arcade game developed using HTML, CSS, and JavaScript. The player controls a spaceship, shoots enemies, avoids collisions, and tries to achieve the highest score.

## 🎮 Features
- 🚀 Player-controlled spaceship
- 🔫 Shoot bullets to destroy enemies
- 👾 Enemies appear on the screen
- 💥 Collision detection
- 🏆 Score tracking
- 🎯 Game over when the player loses
- 🌐 Runs directly in a web browser

## 🛠️ Technologies Used
- **HTML5** — Game structure
- **CSS3** — Styling and visual effects
- **JavaScript** — Game logic and controls

## ▶️ How to Run the Game
1. Download or clone the project.
2. Open the `space-shooter` folder.
3. Double-click `index.html`.
4. The game will open in your web browser.
5. Start playing!

## 🎯 How to Play
- **Left Arrow / A:** Move left
- **Right Arrow / D:** Move right
- **Spacebar:** Shoot bullets
- **Objective:** Destroy enemies and earn points while avoiding collisions.

*Controls may vary depending on the implementation.*
